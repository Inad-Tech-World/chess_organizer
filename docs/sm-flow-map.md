# Arbiter workflow map (template)

Phase 0 deliverable: a written map of the workflow arbiters already know
from existing tournament software. Fill it in from the free demo of the
reference program (Windows), recording **only what an arbiter does and
sees as functionality**. Never copy screenshots, icons, manual text or file
layouts (see [legal.md](legal.md)).

For each screen, record its purpose, the fields, the actions and keyboard
shortcuts, and the Chess Organiser screen that covers it.
